# Goal: Hello World

My first Rust program. It doesn't need to do much. The point is to get Rust set up and see how a Rust project works.

## What it should do

When I run the program, it prints the following to the terminal:

```
Hello, world!
```

## What I want to learn

- Installing Rust and checking that it works (`rustc --version`, `cargo --version`)
- Creating a new project with `cargo new`
- What a Cargo project contains: `Cargo.toml`, `src/main.rs`, and the `target/` folder
- The `main` function as the entry point of a program
- Printing text with the `println!` macro
- Building and running with `cargo build` and `cargo run`

## Done when

- [ ] `cargo run` prints `Hello, world!`
- [ ] I can explain what each line in `src/main.rs` does
- [ ] I know why `println!` has a `!` (it's a macro, not a function)
