# Module 1: Why is the compiler yelling at me?

Install the toolchain, ship a first binary, and model a log line with Rust's type system.

## By the end of this module you can

- Create, build and run a Cargo project in debug and release mode
- Use bindings, mutability, shadowing and the core scalar types deliberately
- Model domain data with structs and enums and branch on it exhaustively with match

## Lessons

1. **Hello cargo: ship a binary** — Install rustup, create crumbs with cargo, run it, and see why release builds matter.
2. **Variables, types, mutability, shadowing** — Why let is immutable by default, what the integer types are for, and when shadowing beats mut.
3. **Structs, enums and match: modelling a log line** — Turn a raw nginx access-log line into a typed LogEntry with an HttpMethod enum.
