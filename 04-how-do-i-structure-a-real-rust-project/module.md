# Module 4: How do I structure a real Rust project?

Traits, generics, modules, a proper CLI, and tests.

## By the end of this module you can

- Define and implement traits, including derived standard traits
- Write generic functions and types with trait bounds
- Split a crate into modules and a lib + bin and add a clap CLI
- Write unit, integration and doc tests

## Lessons

1. **Traits and derive** — Teach LogEntry to print itself, compare itself and render as table or JSON.
2. **Generics and trait bounds** — One stats function that works over any source of log lines.
3. **Modules, lib + bin, and clap** — Turn crumbs from one main.rs into a real crate with a real CLI.
4. **Testing: unit, integration and doc tests** — Lock down the parser before you make it fast.
