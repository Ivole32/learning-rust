# learning-rust

I'm a backend engineer (Python/JS) learning Rust in public. This repo holds everything: the course I'm working through, my quiz answers and assignments, and the project I'm building along the way.

**The project: `crumbs`.** I inherited a fleet of services whose only observability is a 4 GB nginx access log, plus a Python script that takes 11 minutes to answer "what broke at 3am?". `crumbs` is the Rust rewrite. It starts as a CLI log analyzer and ends as `crumbs-server`, an HTTP ingestion and query service (axum + sqlx).

- 🦀 **Code:** [`crumbs/`](crumbs/) (appears after lesson 1)
- 📚 **Lessons:** one folder per module below, each with lesson, examples, quiz, assignment and my submission

## Course: Rust for backend engineers: building crumbs

A gated, hands-on course generated by the **learn-anything** skill.
Depth: **practitioner**  ·  Goal: **Backend engineer (Python/JS) learning Rust; publish all work publicly on GitHub; extend to Deep-level modules later**  ·  Pass mark: **70%**

## How this works

1. Open `progress.html` in a browser to see where you are.
2. Work through modules **in order**. Lessons unlock one at a time.
3. Each lesson gives you content, worked examples, a quiz, an assignment, and a
   spoken explain-back check. Your tutor grades all three — you need **70%**
   on each to move on.
4. Passed lessons come back as **spaced-repetition reviews** days and weeks later.
   Let too many pile up and new lessons stop unlocking until you clear them.
5. Each module ends with a cumulative test. Passing it unlocks the next module.
6. Finish every module to unlock the final project.

You cannot skip ahead. That is the point. If you already know a module, ask to be
**tested out** of it — you take the module test cold at a higher bar (85%).

## Modules

1. **Why is the compiler yelling at me?** — Install the toolchain, ship a first binary, and model a log line with Rust's type system. (3 lessons)
2. **Who owns this string?** — Ownership, moves and borrowing: the rules that replace a garbage collector. (4 lessons)
3. **What happens when the input is garbage?** — Errors as values, collections, iterators, and streaming huge files. (4 lessons)
4. **How do I structure a real Rust project?** — Traits, generics, modules, a proper CLI, and tests. (4 lessons)
5. **Can it use all my cores?** — Lifetimes, smart pointers, threads and the async mental model. (4 lessons)
6. **Ship it as a service** — crumbs becomes crumbs-server: an HTTP API with a database, tracing and CI. (4 lessons)

## Final project

**crumbs-server** — A log ingestion and query service that replaces the 11-minute Python script: ingest nginx logs over HTTP, persist them, and answer 'what broke at 3am?' in milliseconds.
