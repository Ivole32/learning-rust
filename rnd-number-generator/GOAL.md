# Goal: Random Number Generator

A small program that generates a random number and prints it to the terminal.

## What it should do

1. Generate a random whole number between 1 and 100 (both included).
2. Print it.

Example:

```
Your random number is 42
```

## What I want to learn

- Adding an external crate as a dependency in `Cargo.toml`
- Finding and reading a crate's documentation
- Bringing a crate's items into scope with `use`
- Using a random number generator
- Writing inclusive and exclusive ranges

## Done when

- [ ] Every run prints a number between 1 and 100
- [ ] Running it several times gives different numbers
- [ ] Both 1 and 100 can come up
- [ ] I can explain the difference between `1..100` and `1..=100`
