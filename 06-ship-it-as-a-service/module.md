# Module 6: Ship it as a service

crumbs becomes crumbs-server: an HTTP API with a database, tracing and CI.

## By the end of this module you can

- Serialise and deserialise JSON with serde
- Build an axum HTTP API with routing, extractors and shared state
- Persist and query data with sqlx and SQLite
- Map errors to HTTP responses, add tracing, and run tests in GitHub Actions

## Lessons

1. **serde: JSON in and out** — Derive Serialize/Deserialize and control the wire format.
2. **An HTTP API with axum** — Routes, extractors and shared state for ingesting and querying logs.
3. **Persistence with sqlx and SQLite** — Store ingested entries and query stats with compile-time-checked SQL.
4. **Errors as responses, tracing and CI** — Production polish: IntoResponse errors, structured logs and a green pipeline.
